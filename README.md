# Bộ công cụ Lịch báo giảng

Gồm 3 trang chính:

- `index.html`: Trang chính với 2 nút chức năng.
- `Chuan_hoa.html`: Chuẩn hoá LBG.
- `Ghep_LBG.html`: Ghép LBG THCS & THPT.
- `favicon.svg`: Biểu tượng trang.

## Cách chạy

Mở `index.html` bằng Chrome, Edge hoặc Firefox. Hai chức năng xử lý Excel sử dụng ExcelJS từ CDN, vì vậy cần kết nối Internet để tải thư viện trong lần mở trang.

## Đưa lên GitHub Pages

Tải toàn bộ 4 tệp lên cùng một repository, sau đó bật **Settings → Pages → Deploy from a branch** và chọn nhánh chứa `index.html`.
